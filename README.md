# CardsAbroad — сайт про зарубежные карты для россиян (2026)

Статический сайт-блог + лендинги по оформлению иностранных банковских карт.
Генерируется из исходников скриптом на чистом Python (без зависимостей).

**Живой сайт:** https://slavasaharov93-dotcom.github.io/cards-blog/

## Как запустить локально

1. Установить Python 3.x (с галочкой «Add Python to PATH»).
2. Двойной клик по `ЗАПУСТИТЬ-САЙТ.bat` — сайт соберётся и откроется в браузере.

Или вручную:

```bash
python build.py        # собрать сайт в dist/
python serve.py 8000   # запустить просмотр на http://127.0.0.1:8000/
```

## Что где менять

| Что | Файл |
|-----|------|
| Цены и каталог карт (страны, цены, условия) | `offers.json` |
| Статьи блога | `articles/*.json` |
| Тексты страниц, меню, контакты | `build.py` |
| Дизайн и цвета | `assets/styles.css` |
| Картинки | `assets/img/` |

После правки — снова `python build.py` и обновить страницу (F5).

## Структура

- `build.py` — генератор сайта (вся логика и тексты страниц)
- `serve.py` — локальный сервер для просмотра
- `offers.json` — данные по картам
- `articles/` — статьи блога в JSON
- `assets/` — стили, иконки, изображения
- `dist/` — результат сборки (в репозиторий не коммитится)
