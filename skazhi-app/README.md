# Скажи 🗣️

Приложение с карточками (AAC / PECS) для людей с аутистическими особенностями.
Помогает «говорить» через картинки: нажимаешь карточки — приложение собирает
фразу и произносит её вслух. iOS и Android из одного кода на **React Native (Expo)**.

> Статус: ранний MVP (первый рабочий экран). Работает офлайн, без аккаунта.

## Что уже умеет

- 📇 Сетка карточек с категориями (Главное, Еда, Чувства, Действия, Люди).
- 🔊 Озвучка по нажатию (offline TTS устройства, русский язык).
- 🧩 Полоска фразы: тапаешь карточки → собирается предложение → кнопка «Сказать».
- ↩️ Удаление последней карточки и очистка фразы.
- 🎨 Спокойная палитра и крупные элементы — комфортно для пользователей с РАС.

## Идея и место на рынке

В отличие от дорогих англоязычных AAC-приложений ($200–300), «Скажи» делает ставку на:
- **русский язык** и рынок СНГ (almost не покрыт);
- **личные фото** вместо стоковых символов (план);
- **бесплатно, офлайн, без аккаунта** — приватность данных ребёнка;
- простой **родительский режим** для добавления своих карточек (план).

## Запуск (разработка)

Нужен Node.js 18+ и приложение **Expo Go** на телефоне.

```bash
cd skazhi-app
npm install
npm start
```

Отсканируй QR-код из терминала приложением Expo Go (Android) или Камерой (iOS).

> Примечание: для иконки/сплэша добавь картинки в `./assets` (icon.png и т.д.)
> или убери соответствующие поля из `app.json` — для запуска в Expo Go они не критичны.

## Сборка нативных приложений (позже)

Для публикации в App Store / Google Play используется EAS Build:

```bash
npm install -g eas-cli
eas build --platform android
eas build --platform ios
```

## Структура

```
skazhi-app/
├── App.js                     # Главный экран: сетка + фраза + категории
├── app.json                   # Конфигурация Expo
├── src/
│   ├── theme.js               # Палитра и размеры
│   ├── data/cards.js          # Словарь карточек (демо-набор)
│   └── components/
│       ├── CardTile.js        # Карточка
│       ├── CategoryTabs.js    # Вкладки категорий
│       └── PhraseBar.js       # Полоска фразы + «Сказать»
```
